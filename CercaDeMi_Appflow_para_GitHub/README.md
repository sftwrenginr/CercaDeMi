# CercaDeMi

Aplicación Ionic Angular y Capacitor para buscar lugares cercanos.

## Compilación web

`npm ci` y `npm run build`. Appflow: seleccionar el commit con este código, destino Web y activar Web Preview.

## Funciones

El usuario concede permiso de ubicación; Leaflet muestra el mapa y Overpass busca restaurantes, tiendas y turismo en 1.5 km. El botón Compartir entrega un enlace con la última posición.
